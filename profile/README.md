# BugDrop

**Website feedback, straight to GitHub Issues.**

BugDrop is an open-source widget for bug reports, ideas, and ratings. Reports can include annotated screenshots and browser details, giving teams the context they need in GitHub.

- [Try the live demo](https://bugdrop.dev/demo)
- [Install BugDrop](https://bugdrop.dev/docs/installation)
- [Read the documentation](https://bugdrop.dev/docs)
- [Explore the source](https://github.com/bugdrophq/bugdrop)

One script tag to get started. MIT licensed and self-hostable.
